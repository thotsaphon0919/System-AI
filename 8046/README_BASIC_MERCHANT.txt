INFINI POINT TOWER — BASIC MERCHANT MVP

ระบบนี้ทำแบบง่ายตามที่คุยกัน

1. คนซื้อสำเนาการ์ดจ่ายมูลค่าการ์ด + ค่าระบบ 5%
2. ระบบกันมูลค่าการ์ดไว้เต็มจำนวนให้ร้านค้า
3. ผู้ถือการ์ดนำ QR หรือลิงก์ไปใช้กับร้านค้าที่ผ่านระบบ
4. ร้านวาง URL / Token / เลขการ์ด ทีละบรรทัด
5. ระบบตรวจของจริง นับจำนวน และรวมยอดให้อัตโนมัติ
6. ถ้ามีใบผิดหรือใช้แล้ว ระบบไม่ปิดทั้งชุด
7. เมื่อผ่าน ระบบปิดทุกใบและสร้างเลขชุดรับแลก
8. MVP ใช้อัตราทดลอง 1 INF = 1 บาท
9. รางวัลพิเศษยังแลกกับ Point Tower โดยตรง แยกจากร้านค้า

- ควรเปลี่ยนเป็นระบบล็อกอินจริงก่อนเปิดให้คนทั่วไปใช้
