INFINI Point Tower — Card Template Gallery

หน้าใช้งาน:
  http://127.0.0.1:8046/tower/cards

การทำงาน:
1. อัปโหลดรูป/วิดีโอลายการ์ดเต็มใบ หรือเลือกลายตัวอย่าง
2. แตะการ์ดเพื่อเปิดหน้ารายละเอียด
3. ใส่จำนวนสำเนา ระบบคำนวณราคารวมทันที
4. ซื้อแล้วระบบออกเลขและ QR ไม่ซ้ำให้ทุกใบ
5. หน้าเสร็จจะดาวน์โหลด ZIP อัตโนมัติ และมีปุ่มดาวน์โหลดซ้ำ
6. ZIP มี QR, links.txt, cards.csv, manifest.json, index.html และไฟล์แม่แบบ

หมายเหตุ:
- การ์ดจริงคือ URL ที่ตรวจจากเซิร์ฟเวอร์ ไม่ใช่รูปหรือวิดีโอที่คัดลอกอย่างเดียว
- ระบบใช้ข้อมูลเดิมใน data/point_card_system.json และไม่ใส่ไฟล์ data มาใน ZIP
- มีโค้ด QR แบบ SVG ฝังมาในโฟลเดอร์ qrcode พร้อมใบอนุญาต BSD
